# ✈️ Flappy Plane

Flappy Plane은 Unity를 사용하여 제작한 2D 아케이드 게임으로, Flappy Bird를 모티브로 제작된 모작 게임입니다.  
마우스 클릭으로 비행기를 조작하며 장애물을 피하고 가능한 한 많은 점수를 얻는 것이 목표입니다.

## 🎮 게임 소개

- **조작법**: 마우스 클릭 시 비행기가 위로 점프합니다.
- **게임 목표**: 장애물을 피하면서 가능한 한 많은 점수를 획득하세요.
- **게임 오버 조건**: 벽 또는 장애물과 충돌하면 게임이 종료됩니다.
- **게임 재시작**: 게임 오버 후, 마우스를 클릭하면 게임이 다시 시작됩니다.

## 🛠️ 주요 기능

| 기능            | 설명 |
|----------------|------|
| 점프           | velocity를 이용한 위 방향 점프 처리 |
| 점수 시스템    | 장애물을 통과할 때마다 점수 1점 증가 |
| 충돌 감지      | OnCollisionEnter2D / OnTriggerEnter2D 사용 |
| UI 관리        | 점수 표시 및 게임 오버 시 메시지 출력 |
| 게임 상태 관리 | 게임 중 / 게임 오버 상태 전환 및 재시작 로직 구현 |


## 🧠 개발 포인트

- Unity 2D 물리 시스템과 입력 이벤트 처리에 대한 이해
- 간단한 게임 루프와 상태 전환 로직 구성 경험
- 점수 및 UI 업데이트 관리 방법 익힘

## 🚀 향후 개선 아이디어

- 배경 음악 및 효과음 추가
- 난이도 상승 시스템 (장애물 속도 증가 등)
- 게임 기록 저장 (최고 점수 등)
